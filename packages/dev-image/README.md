# Spear AI Dev Image

A Docker image with a common set of tools used by Spear.

| Tool                                              | Versions   | Description                                         |
| ------------------------------------------------- | ---------- | --------------------------------------------------- |
| [Ubuntu](https://ubuntu.com)                      | `24.04`    | Linux distribution based on Debian                  |
| [direnv](https://direnv.net)                      | `2.32.1`   | Load environment variables in the current directory |
| [Docker](https://www.docker.com)                  | `29.8.1`   | Self-sufficient runtime for containers              |
| [Docker Compose](https://docs.docker.com/compose) | `5.5.1`    | Define and run multi-container Docker applications  |
| [Git](https://git-scm.com/)                       | `2.55.0`   | Distributed version control system                  |
| [fnm](https://github.com/Schniz/fnm)              | `1.39.0`   | Fast and simple Node.js version manager             |
| [Node.js](https://nodejs.org)                     | `24.21.0`  | Back-end JavaScript runtime environment             |
| [pnpm](https://pnpm.io)                           | `11.1.3`   | Fast, disk space efficient package manager          |
| [pyenv](https://github.com/pyenv/pyenv)           | `2.8.6`    | Simple Python version management                    |
| [Python](https://www.python.org)                  | `3.11.16`  | High-level, general-purpose programming language    |
| [uv](https://docs.astral.sh/uv)                   | `0.12.20`  | Extremely fast Python package and project manager   |
| [Pulumi](https://www.pulumi.com)                  | `3.265.0`  | Universal infrastructure as code                    |
| [Vim](https://www.vim.org)                        | `9.1.0016` | Improved version of the good old UNIX editor Vi     |
